========================
一、游戏基础设定
========================
1. 游戏类型：多人策略推理游戏（阵营对抗）
2. 玩家人数：支持 5~10 人（必须可配置）
3. 阵营：
   - 好人阵营（蓝方）
   - 坏人阵营（红方）

4. 胜利条件：
   - 好人阵营：完成 3 次任务成功
   - 坏人阵营：让 3 次任务失败，或刺杀梅林成功

========================
二、角色系统（必须支持自定义开关）
========================
基础角色：
- 梅林（Merlin）：知道所有坏人（除莫德雷德）
- 派西维尔（Percival）：知道梅林和莫甘娜，但无法区分
- 忠臣（Loyal Servant）：普通好人
- 刺客（Assassin）：坏人，最后可以刺杀梅林
- 爪牙（Minion）：普通坏人

扩展角色（可选）：
- 莫甘娜（Morgana）：伪装成梅林
- 莫德雷德（Mordred）：梅林看不到
- 奥伯伦（Oberon）：坏人，但不被其他坏人知道

要求：
- 角色必须支持自由启用/禁用
- 自动根据人数推荐角色组合
- 允许用户自定义角色池

========================
三、推荐人数与角色配置（必须内置）
========================
5人：
- 2坏人：刺客 + 爪牙
- 3好人：梅林 + 忠臣×2

6人：
- 2坏人：刺客 + 爪牙
- 4好人：梅林 + 派西维尔 + 忠臣×2

7人：
- 3坏人：刺客 + 莫甘娜 + 爪牙
- 4好人：梅林 + 派西维尔 + 忠臣×2

8人：
- 3坏人：刺客 + 莫甘娜 + 爪牙
- 5好人：梅林 + 派西维尔 + 忠臣×3

9人：
- 3坏人：刺客 + 莫甘娜 + 莫德雷德
- 6好人：梅林 + 派西维尔 + 忠臣×4

10人：
- 4坏人：刺客 + 莫甘娜 + 莫德雷德 + 奥伯伦
- 6好人：梅林 + 派西维尔 + 忠臣×4

========================
四、游戏流程（核心状态机）
========================
游戏必须实现以下阶段：

1. 初始化阶段：
   - 分配角色（随机）
   - 发送身份信息（私密信息）

2. 夜晚信息阶段：
   - 梅林看到坏人（除莫德雷德）
   - 派西维尔看到梅林/莫甘娜
   - 坏人互相确认（奥伯伦例外）

3. 回合循环（最多5轮）：
   每轮包括：

   (1) 队长选择队伍成员
   (2) 全员投票（通过/否决）
       - 连续5次否决 → 坏人胜利
   (3) 任务执行：
       - 队员秘密投票（成功/失败）
       - 统计结果（部分人数需要2失败才失败）

任务人数配置（必须支持动态）：
5人局：[2,3,2,3,3]
6人局：[2,3,4,3,4]
7人局：[2,3,3,4,4]
8~10人局：[3,4,4,5,5]

特殊规则：
- 第4轮（7人以上）需要2个失败才算失败

4. 胜负判定：
   - 好人3胜 → 进入刺杀阶段
   - 坏人3胜 → 直接胜利

5. 刺杀阶段：
   - 刺客选择一名玩家
   - 若刺中梅林 → 坏人胜利
   - 否则 → 好人胜利

========================
五、系统设计要求
========================
必须实现：
- 房间系统（创建/加入/退出）
- 玩家状态管理（在线/准备）
- 游戏状态机（严格控制阶段流转）
- 投票系统（匿名/公开）
- 日志系统（记录每轮结果）
- 可扩展角色机制（策略模式或枚举+配置）
